# 锤子音乐 v1.0.0

基于 [lx-music-mobile](https://github.com/lyswhut/lx-music-mobile) 改造，保留洛雪全部音乐能力，界面重制为锤子（Smartisan）音乐播放器风格。

### 界面

- 全站锤子风：首页 5 Tab（搜索 / 歌单 / 排行榜 / 我的列表 / 我的）、居中标题栏、发丝分隔线、分段式排序条
- 播放页：黑胶唱盘 + 唱臂 + 大圆播放键，模糊歌词页（当前行高亮 `#325AB1`）
- 迷你播放条：圆形封面、白色圆底四按钮（收藏 / 上一首 / 播放 / 下一首）、底部红色进度线
- 设置改为独立页面，二级分类 6 项；所有勾选框、单选项、拖动条统一锤子风格
- 歌曲「更多」操作改为底部四列图标弹层
- 桌面图标、应用名（锤子音乐）与包名（`x.mc.sos`）替换

### 功能

- 「我的」页：我的收藏、本地音乐、播放历史、定时停止、自定义源管理、设置、关于
- 新增**播放历史**独立页面，独立持久化存储（不随机模式下也会记录）
- 我的收藏 / 本地音乐改为独立页面
- 我的列表顶部条：固定「试听列表」+ 最近打开的列表，其余收进「更多」

### 说明

- 洛雪 v1.9.x 已下线内置音源，在线播放需在「设置 → 基本设置 → 自定义源管理」导入自定义音源脚本
- 基于 React Native 0.73.11 构建
